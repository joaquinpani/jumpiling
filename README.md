# Starlight

Hi a person that is viewing my README of Starlight!

I'm going to say what is this. Starlight is a video game from Jumpstart. And yeah I made it for the Jumpstart program. I experimented with it I'm not gonna lie but its a good game. I just want to do a rhythm game because I never do a rhythm game. So this is one. And the principal and the only music that I use is "Satellite" by Bebe Rexha and Snoop Dogg.

## What is this?

You need to move and avoid the stars. Yeah the stars are bad. You dont need to touch them. If you touch the stars you are going to miss the game. Game over.

So what you need to do with W S A and D you need to move over the sun and avoid all the stars. You are a character a very very baddish character and you need to avoid all the stars if you can. And thats all the game.

## Controls

- W: Up
- S: Down
- A: Left
- D: Right
